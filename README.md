## **Abstract**
This paper examines the need for providing individuals with autism spectrum disorder with adequate support systems and the use of technology for increasing the effectiveness of such interventions as well as fostering social inclusion is examined. It provides a systematic comparison between AI, mobile applications, VR, and wearable technologies to find the best means of addressing ASD.
